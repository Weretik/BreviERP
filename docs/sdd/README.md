# Документація BreviERP

Цей каталог є джерелом істини для архітектури та розробки за специфікаціями (SDD).

- [Архітектура](architecture/README.md) — фактична топологія backend-а та межі модулів.
- [Стандарти](standards/README.md) — обов’язкові правила реалізації й документації.
- [Експлуатація](operations/README.md) — runtime-конфігурація, запуск, діагностика та задачі.
- [Специфікації](specs/README.md) — одна папка на кожну заплановану функціональність і багаторазові шаблони.

Не створюйте один великий design document. Стале правило зберігайте в architecture або standards; рішення, специфічні для функціональності, зберігайте в її специфікації.
