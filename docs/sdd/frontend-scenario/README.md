# Frontend-сценарії SDD

Тут зберігаються сценарії інтерфейсу, згруповані за модулем і feature: `<module>/<NNN>-<feature>/<actor>-<entity>-scenario.md`. Вони описують дії користувача й використання наявних API; вимоги та backend design залишаються в `docs/sdd/specs/`, а машинні HTTP-контракти — в `docs/sdd/contracts/`.

Новий сценарій створюйте за [інструкцією](../specs/_templates/frontend-scenario/README.md), додавайте до індексу модуля й пов'язуйте з README відповідної feature.
