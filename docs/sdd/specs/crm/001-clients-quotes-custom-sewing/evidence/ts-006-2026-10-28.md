## Observable result

- Create/read/revise a private custom draft with product type/season, name, public description/comment, internal note, fabrics/accessories/operations, application cost/approved sale, delivery/packaging and optional customer/quote links. Incomplete composition remains editable and calculation returns typed blockers.
- Explicit calculation creates a server-held 15-minute token bound to actor/draft/revision and exact approved source versions. Freeze accepts token/revision only; no browser totals. Expired/foreign/stale/blocked bases and changed sources never create a partial version.
- Save immutable independently named fabric alternatives, page version history and read an exact prior version. Root changes, versions and response journaling commit atomically; same-key replay is exact, changed payload conflicts, current access is rechecked.
- Hydrate quote variants by stored custom version ID, with a restrictive numeric FK and typed saved configuration/basis. Later draft/V2 changes do not alter quote V1; explicit V2 selection creates a new quote version. Copy preserves V1 without recalculation. Text-only writes retain stored basis. Selected custom versions are fetched in one bounded SQL batch.
- Unattached roots follow owner/Admin; quote-linked roots follow current quote ownership/Admin. A new assigned quote owner can resolve the exact custom versions already pinned in that quote without gaining edit access to a foreign originating root. Old cached preview replay is denied after access loss.
