## Open decisions

The user confirmed the old Calculator default company details as current and approved its PDF wording unchanged: `Усі ціни вказані в грн з ПДВ.` New numbers have the form `N/M/YYYY`, with `10/10/2026` as the example. The shared monthly sequence starts at 10 and the number is allocated on ready, under an atomic database lock. Existing imported numbers keep their original text and reserve their numeric slot for that period when they are present in Crm. A later import must detect any collision with numbers issued in the meantime rather than silently renumbering history. The legacy generator uses UTC for month/year; retain that technical period basis.

New ready documents use only the active issuer/template versions; previously issued documents preserve their pinned versions. If no verified version is active, ready remains blocked while draft save remains available. The source has no separate bank name/MFO field; do not infer either from the IBAN. The logo source is `/brand/brevi-wordmark.svg`; backend use requires a provisioned server-managed asset key rather than remote URL fetching.

Acceptance examples: if no number exists for October 2026, the first ready quote receives `10/10/2026`; the next receives `11/10/2026`. If historical `12-10-2026` is already imported, the allocator skips slot 12. Two concurrent ready requests in one period receive distinct consecutive numbers. A revised or inactive seller version does not change an existing issued PDF.
