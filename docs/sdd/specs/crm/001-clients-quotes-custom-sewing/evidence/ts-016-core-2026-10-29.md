Target SDD explicitly requires versioned Catalog ProductId mappings instead of name guesses.
- Catalog `SewingArticle.Id` is the sellable long ArticleId for a product, while material fabric references are separate `FabricReferenceId` values. The new types therefore name the selected identity `ArticleId`, not `FabricArticleId`.
