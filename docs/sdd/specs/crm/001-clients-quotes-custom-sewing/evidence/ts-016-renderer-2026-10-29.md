## Integration boundary

`QuoteVersion` now has an optional typed `IntroductionPublicSnapshot`, and `CreateQuoteCommand` accepts it for the application-owned introduction creation path. Before persistence, `IntroductionQuotePinValidator` checks each selected product/article and the visible large-wholesale price against the actual built quote items. `PrepareQuote` and `QuotePdfWorker` select the introduction projection from the pinned version; ordinary versions still use the existing standard projection. Ordinary edit, reprice and copy operations reject introduction versions with `introduction_requires_new_from_template` until a typed workflow can regenerate the public snapshot alongside prices.

`QuoteVersionConfiguration` stores the optional snapshot as nullable `jsonb`; migration `20261029174047_AddIntroductionQuotePublicSnapshot` adds only that column after `20261029173840_AddIntroductionTemplatesAndFeaturedMapping`. `IntroductionPublicSnapshotJson` materializes and freezes the interface-typed slot list on database read. A future API path must supply `Freeze(prepared)` and matching `QuoteDraftContent` to `CreateQuoteCommand`; no HTTP endpoint is added in this slice.
