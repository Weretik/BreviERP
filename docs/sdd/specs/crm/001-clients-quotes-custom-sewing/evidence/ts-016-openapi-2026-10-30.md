# TS-016 introduction API contract — 2026-10-30

## Scope

Canonical `docs/sdd/contracts/crm/introduction-templates.openapi.yaml` documents the nine implemented introduction operations from `IntroductionTemplatesController` and `IntroductionFeaturedMappingController`. The coordinator adds the six aggregate path references separately; this package does not modify the aggregate or runtime.

The contract covers Manager-owned template create/list/read/revise/archive/check/apply, Admin management across owners, and Admin-only exact source-mapping activation. Requests reject unknown members. Create requires omitted/null expectedRevision; revise requires positive expectedRevision. Apply returns the existing `CrmQuoteDetail`, creating a draft only. Check is read-only GET. List retains `value/pagedInfo`, includeArchived, bounded page/pageSize. Model codes are bounded to 80 by Domain validation.

## Wire details and compatibility

Request layout is `general|summer|winter`. Response layout uses the current numeric enum `0=General,1=Summer,2=Winter`; season uses `0=Summer,1=Winter`. Slot includes serialized computed `uid` (100–103/200–203). No global string-enum converter exists in current Host/BuildingBlocks sources. A later conversion to string response enums is a contract change.

Existing shared `CrmQuoteCatalogPrice`, `CrmQuoteDetail`, and `CrmPagedInfo` schemas are referenced rather than copied. Prepared output is an internal authenticated Manager/Admin check result; PDF uses a separate public projection. Actor/owner, prices, mapping numeric ProductIds and timestamps are not accepted as authoritative template-write fields.

Template mutations use actor-bound requestId with payload conflicts; apply replay is being fixed in the separate implementation package and requires its regression evidence before the parent may close the replay finding. Featured mapping PUT accepts no requestId; identical active source triple and resolved identities reuse the active version. HTTP 400 covers business blockers under the existing Result mapper; 422 is not introduced. Missing/foreign templates use 404, role denial 403, revision/archive/mapping/source conflicts 409 where implemented.
