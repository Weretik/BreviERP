## Remaining EN-002 design checkpoint

Reproducible approved-engine fixtures for the adapter boundary: Sewing Article 246 on the frozen 13-operation MOD-025 source has retail/wholesale/large tiers `1169.74 / 996.17 / 943.34`; Article 247 has `1582.66 / 1347.81 / 1276.34` (Catalog sewing evidence). The synthetic PPE fallback input `supplierCost=518.64`, approved markups `0.50 / 0.36 / 0.30` yields `777.96 / 705.35 / 674.23`; approved external `retail=237`, `wholesale=187.90` yields `237 / 212.45 / 187.90` (existing `PpePricingTests`). These are comparison fixtures, not hardcoded runtime prices. For each, the adapter must carry actual saved source-version IDs and the formula version alongside the tiers.

The public Sewing publication DTO contains price tiers and calculation ID but omits the saved calculation's composition/settings/reference versions. The implemented Host quote adapter resolves and freezes those versions server-side. The token's persisted basis, actor/input hash, expiry, replay behavior and conflict outcomes are in the [protocol](../design/quote-preview-protocol.md) and canonical quote OpenAPI. Current PPE pricing returns versioned offer/rule IDs. The user confirmed draft UAH and no additional VAT calculation on 2026-10-26 (D-11); customer-ready tax wording remains with EN-005.
