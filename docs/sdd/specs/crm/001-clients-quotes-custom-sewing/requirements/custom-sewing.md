# Private custom sewing

## Rules

- **R-S01:** Custom sewing is a private Crm configuration/draft with immutable versions and optional client/quote linkage, not a published Product. Capture name, product type, season, client description/comment, private note; fabrics, accessories and operations with positive quantities/time; applications (embroidery/print, location/artwork, internal cost and separately approved sale amount); delivery and packaging. Separate pricing, file, template and document responsibilities.
- **R-S02:** Require at least one fabric and one operation to calculate; references resolve through approved current inputs. Model/fabric alternatives are independent named versions/variants with their own composition and prices. Files link to a specific version with independent `showInQuote` and `production` flags. Freeze each selected custom version when inserted into a quote. Later draft edits do not alter an existing quote.
- **R-S03:** Common backend engine owns calculation. No JS floating point engine, hardcoded fallback coefficients, special operation-ID norms or assembly surcharge twice. Legacy observed breakdown: fabric + accessories + operation labour + production overhead + delivery + packaging, then sewing tier factors; application cost participates in internal total cost, while its separately approved **sale amount is added once to each offered tier**. The exact target adapter must be reconciled with the workbook-derived backend formulas before enablement (EN-002); do not multiply the application sale price by a sewing factor or charge its cost twice.
- **R-S04:** Missing/unapproved reference cost, norm, rule, tax basis or required file blocks the dependent calculation/ready action with a specific reason. Preserve an editable blocked draft. UI cannot post wage/overhead/factors as trusted values. All resolved versions and rounding stages enter the immutable calculation basis.
- **R-S05:** Suggestions and templates store selections/norms, not frozen current supplier prices. Suggestions group active approved unique models by product type/season, indicate sample size/varying norm, require explicit application and never silently overwrite input. Ignore ambiguous references. Reusing a template resolves current inputs and creates a fresh private draft/version; quoted historical templates remain unchanged. A custom-configuration template may also contain customer-facing introduction text, never private cost data in its public projection. First-contact Catalog selection/layout templates are a separate typed template kind described in [introduction requirements](introductions.md).
- **R-S06:** Private attachment metadata is not a file. Verify actual uploaded bytes, declared/actual MIME, size, hash and ownership; permit only an explicit allowlist. Suggested initial allowlist is PDF/JPEG/PNG, maximum 20 MiB each, 30 files per configuration, finalized under EN-003 with the storage adapter. Private/production-only files and internal costs must not appear in client PDF/email projections. An archived version retains its referenced files under the retention policy.
- **R-S07:** Production export is an explicit package from a pinned quote/custom version: selected variant, units/norms, operations, permitted production attachments and wage basis. It excludes customer-private financial data and delivery secrets. Generating the package records version/hash but does not send it to Workshop or create an order.

## Scenarios

| ID | Given | When | Then |
| --- | --- | --- | --- |
| SC-S01 | Fabric/operation inputs with approved versions | Calculates and saves two fabric alternatives | Each has its own server result and immutable custom version; saving into a quote pins the selected versions |
| SC-S02 | Applications, delivery and packaging plus positive base composition | Calculates against the approved fixture | Internal cost and each offered tier match EN-002 arithmetic; no assembly/application duplication |
| SC-S03 | A custom V1 already in a quote | Edits the draft and its files | Existing quote V1/file visibility remains unchanged; selecting V2 is a visible new quote change |
| SC-S04 | Reusable template and type/season suggestions | Applies selections then calculates after input costs change | Explicit current-input calculation produces a new draft; neither suggestions nor template silently replace historical prices |
| SC-S05 | Private/production-only file, guessed identifier or spoofed MIME | Uploads, reads or exports it | Validation/ownership checks reject invalid access; only explicitly customer-visible valid files enter the PDF projection |
| SC-S06 | Pinned ready quote and selected option | Exports a production package | Version/hash and permitted composition/files are fixed, no external production task is created |
