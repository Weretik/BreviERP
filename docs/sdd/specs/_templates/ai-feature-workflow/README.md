# Регламент поетапної реалізації backend-feature

Виконуйте передану користувачем фазу feature за таким порядком:

1. Знайдіть і прочитайте файл поточної фази в `<feature>/tasks/` та всі
   застосовні `AGENTS.md`.
2. Прочитайте `README.md` feature і документи, на які посилається поточна фаза.
3. Виконайте лише незакриті checkbox-задачі поточної фази; не починайте наступну.
4. Після виконання кожної задачі позначте її `[x]` у файлі поточної фази.
5. Запустіть релевантні перевірки, зафіксуйте результат у документації та надайте звіт.
6. Зупиніться й чекайте явної команди на наступну фазу.

- [Контекст і межі роботи](01-context-and-scope.md) — як знайти фазу,

- [Виконання і фіксація результату](02-execution-and-records.md) — як

- [Перевірка і передача фази](03-verification-and-handoff.md) — як перевірити
  результат і завершити фазу.
