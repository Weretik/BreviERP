# Фаза 02: Реалізація та дані

**Статус:** чернетка  
**Залежить від:** фази 01  
**Блокує:** rollout

## Результат

Реалізацію та будь-який перехід даних завершено за прийнятими контрактами.

## Завдання

- [ ] Реалізувати за шарами невеликими комітами, придатними для рев’ю.
- [ ] Додати міграцію/backfill лише після погодження.
- [ ] Додати валідацію, спостережуваність і тести.
- [ ] Зберігати сумісність старого та нового шляхів контракту протягом визначеного вікна.

## Критерії приймання

- [ ] Автоматизовані перевірки пройдено або точні збої зафіксовано.
- [ ] Перехід даних відтворюваний і безпечний для повтору.
