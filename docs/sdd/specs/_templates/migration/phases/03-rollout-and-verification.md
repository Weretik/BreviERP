# Фаза 03: Rollout і перевірка

**Статус:** чернетка  
**Залежить від:** фази 02  
**Блокує:** завершення

## Результат

Міграцію випущено, вона спостережувана та зворотна.

## Завдання

- [ ] Виконати restore, build і тести.
- [ ] Вручну перевірити поведінку API/інтеграції.
- [ ] Перевірити логи, метрики та цілісність даних.
- [ ] Виконати або відрепетирувати кроки rollback.
- [ ] Зафіксувати залишкові ризики та закрити застарілі шляхи лише після погодженого вікна.

## Критерії приймання

- [ ] Критерії приймання батьківської міграції позначено.
- [ ] Рішення щодо rollback задокументовано.
