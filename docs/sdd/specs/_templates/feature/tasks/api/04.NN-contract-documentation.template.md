- [ ] T065 Оновити `docs/sdd/specs/<module>/<NNN>-<feature>/contracts/api-contract.md` для кожного endpoint: шлях, HTTP method, request, response, статус-коди, авторизація та приклади.

- [ ] T068 Описати в OpenAPI всі схеми, параметри, фільтри, сортування, пагінацію, security requirements і success/error responses.

## Checkpoint

Кожен реалізований endpoint описаний у versioned OpenAPI YAML і має однакові з кодом параметри та відповіді. Не передавати API frontend або integration consumer до проходження цього checkpoint.
