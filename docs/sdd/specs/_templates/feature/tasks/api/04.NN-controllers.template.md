# Шаблон підфази 04.NN — API: контролери та endpoint-методи

- [ ] T050 Перевірити наявний API-патерн у модулі: `Controllers/`, `Contracts/`, `ISender.Send`, `BuildingBlocks.Api` і extension `ToActionResult` для `Ardalis.Result`.
- [ ] T051 Перевірити composition root у `<точний шлях Program.cs/extension>`: чи controller infrastructure вже підключена через `AddControllers()` і `MapControllers()` або еквівалент проєкту.
- [ ] T052 Додати або змінити конфігурацію controller infrastructure лише якщо її немає; не дублювати глобальну реєстрацію для однієї feature.
- [ ] T053 Створити або оновити `<Feature>Controller` у `<точний шлях>` і визначити route group за погодженим API contract.
- [ ] T054 Додати endpoint-метод для `<Get…ListQuery>`: прийняти HTTP-параметри, замапити їх у Mediator request, передати `CancellationToken` і повернути наявний `ToActionResult` mapping.
- [ ] T055 Додати endpoint-метод для `<Get…ByIdQuery>`: отримати route parameter, замапити його в Mediator request, передати `CancellationToken` і повернути наявний `ToActionResult` mapping.
- [ ] T056 Додати endpoint-метод для `<Create…Command>`: прийняти request body, замапити його в команду, передати її до Mediator і повернути наявний `ToActionResult` mapping.
- [ ] T057 Додати endpoint-метод для `<Update…Command>`: узгодити route identifier і request body, замапити їх у команду, передати її до Mediator і повернути наявний `ToActionResult` mapping.
- [ ] T058 Додати endpoint-метод для `<Delete…Command>`: отримати route identifier, замапити його в команду, передати її до Mediator і повернути наявний `ToActionResult` mapping.
- [ ] T059 Додати endpoint-метод для кожного додаткового use case окремою задачею: `<назва use case>`; використати наявний Result-to-HTTP mapping, а новий створювати лише коли це вимагає погоджений contract.

## Checkpoint

Controller infrastructure підключена лише за потреби; кожен погоджений use case має окремий тонкий endpoint, а controller лише виконує HTTP-to-Mediator мапінг.
