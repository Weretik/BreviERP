## Робота

- [ ] T060 Перевірити наявні API contracts і mapping helpers у `<Module>.Api/Contracts`; використати їх, якщо вони відповідають endpoint.
- [ ] T061 Створити API request/response DTO та mapper лише якщо HTTP binding або публічний API contract відрізняється від Application DTO; не використовувати Application DTO як HTTP contract без явного рішення.
- [ ] T062 Перевірити authentication/authorization configuration у composition root; додати policy, role mapping або permission registration лише якщо потрібного правила ще немає.
- [ ] T063 Застосувати погоджену authorization policy/role до кожного endpoint та перевірити, що не виникає broken object/function level authorization.
- [ ] T064 Використати наявний `ToActionResult` для `Ardalis.Result`; не створювати ручний Result-to-HTTP mapping для endpoint, окрім погодженого винятку.
