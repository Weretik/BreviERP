# Граф задач feature

Цей файл індексує заплановані задачі feature. Замініть посилання на шаблони фактичними вибраними файлами й видаліть невикористані шаблони.

## Ідентифікатори

- `R-001`: бізнес-правило в `requirements/`;
- `SC-001`: acceptance-сценарій у `requirements/`;
- `TS-001`: одна відповідальність реалізації або verification;
- `EN-001`: одна спільна відповідальність або передумова.

Checklist IDs усередині задачі є локальними кроками. `TS-*` і `EN-*` — сталі ідентифікатори, які використовує `traceability.md`.

## Фази планування

- [00 — Поведінка й readiness](00-readiness.md)
- [01 — Domain-задачі](01-domain.md)
- [02 — Infrastructure та enablers](02-infrastructure.md)
- [03 — Application-задачі](03-application.md)

- [05 — Verification і delivery](05-verification.md)

Номери фаз упорядковують планування. Реалізація виконується сценарій за сценарієм відповідно до залежностей задач; завершувати цілий шар перед переходом до іншого не потрібно.
