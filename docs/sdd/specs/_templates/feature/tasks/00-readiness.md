# Фаза 00 — Планування поведінки й readiness

> Ця фаза створює behavior-first основу та потрібні readiness-задачі.

- [ ] Підтвердити мету feature, акторів, scope і виключення.
- [ ] Призначити сталі ID `R-*` бізнес-правилам і `SC-*` acceptance-сценаріям.
- [ ] Додати релевантні happy-path, негативні та граничні приклади.
- [ ] Закрити `[NEEDS CLARIFICATION]` або винести їх за scope.
- [ ] Вибрати й створити лише потрібні readiness-файли.
- [ ] Ініціалізувати `traceability.md` одним рядком на кожен сценарій у scope.

## Checkpoint

Кожна змінена поведінка має сталий scenario ID і однозначний спостережуваний результат. Рівні тестування заплановано, відкриті product-рішення закрито або винесено за scope, а traceability matrix містить кожен сценарій.

## Наступний крок планування

Заплануйте технічні задачі, потрібні графу сценаріїв. Під час планування можна досліджувати всі шари до початку реалізації.
