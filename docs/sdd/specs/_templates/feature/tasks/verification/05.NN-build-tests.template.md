# Шаблон підфази 05.NN — Verification: build та automated tests

- [ ] TNN1 Виконати `dotnet restore BreviERP.sln` або погоджений script проєкту.
- [ ] TNN2 Виконати `dotnet build BreviERP.sln --no-restore` або погоджений script проєкту.
- [ ] TNN3 Виконати `dotnet test BreviERP.sln --no-build` або погоджений набір цільових tests.
- [ ] TNN4 Зафіксувати виконані команди, результат і відомі обмеження verification.

## Checkpoint
