# Шаблон підфази 00.NN — Readiness: scope, рішення та CQRS use cases

- [ ] TNN1 Прочитати requirements, design, data-model, contracts і spec checklist; виписати суперечності без припущень.
- [ ] TNN2 Закрити кожен `[NEEDS CLARIFICATION]` або явно винести його за scope.
- [ ] TNN3 До початку Domain погодити повний перелік CQRS use cases: create, update, delete, get by id, get list та інші потрібні сценарії.
- [ ] TNN4 Для кожного погодженого use case визначити request, response, доступ, ключові бізнес-правила, залежності, споживачів і шлях майбутнього contract `docs/sdd/contracts/<module>/<feature>.openapi.yaml`.
- [ ] TNN5 Явно виключити зі scope непотрібні CRUD/use cases та зафіксувати причину; не створювати їх у наступних фазах. Позначити застосовні пункти spec-readiness checklist.

## Checkpoint

Scope, model decisions і повний перелік потрібних та виключених use cases погоджені.
