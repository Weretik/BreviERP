# <назва feature> — API-контракт

**Статус:** чернетка | погоджено

Цей документ містить рішення, призначені для людей: межі контракту, споживачів, сумісність, безпеку, помилки, ідемпотентність та розгортання.

Після погодження створіть машиночитаний OpenAPI-контракт для frontend у `docs/sdd/contracts/<module>/<feature>.openapi.yaml`. Не зберігайте `.openapi.yaml` у папці цієї feature. Додайте на контракт `$ref` з агрегованого `docs/sdd/contracts/openapi.yaml` у межах тієї самої зміни. Це єдине versioned джерело для frontend, генерації клієнтів і контрактних тестів; Swagger UI лише його відображає.

Правила структури й підтримки контрактів наведено в [`docs/sdd/contracts/README.md`](../../../../contracts/README.md).

До погодження визначте маршрути, HTTP-методи, ідентифікатори операцій, DTO, приклади, помилки, безпеку, ідемпотентність для записів із побічними ефектами та шлях міграції для несумісних змін.
