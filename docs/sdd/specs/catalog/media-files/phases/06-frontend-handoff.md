# Фаза 06: Передача frontend-контракту

**Статус:** заплановано

Frontend використовує `mediaFileId` із відповіді на завантаження для майбутніх даних фото Product. Не зберігати секрети або токен оновлення в даних запиту. Інтерфейс має показувати поступ завантаження, помилку валідації, помилку завантаження та можливість видалити неприкріплений файл.

Перед передачею підтвердити: формат відповіді з помилкою, політику доступу, очищення файлів без прив’язки й контракт прив’язування `MediaFileId` до Product.
