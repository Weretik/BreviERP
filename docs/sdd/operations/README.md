# Експлуатація

Цей розділ пояснює, як налаштовано, запускається та діагностується серверний застосунок. Він описує експлуатаційні факти, а не проєктування функціональності; перевірки, специфічні для функціональності, залишаються у її специфікації.

```text
operations/
├── local-development/  запуск API та локальні URL
├── configuration/      джерела конфігурації й робота з секретами
├── data/               запуск міграцій і початкове наповнення через Host.Seed
├── diagnostics/        перевірки стану, Swagger і журнали
├── deployment/         конфігурація контейнерів і Cloud Build
└── jobs/               стан фонових задач і вимоги до майбутніх інструкцій
```

## Читайте відповідно до задачі

- Запустити серверний застосунок локально: [локальна розробка](local-development/run-api.md)
- Налаштувати машину або виправити відсутні параметри: [конфігурація та секрети](configuration/configuration-and-secrets.md)
- Підготувати окремий запуск `Host.Seed`, який змінює базу: [міграції та початкове наповнення](data/migrations-and-seeding.md)
- Перевірити запущений API або відтворити кінцеву точку: [діагностика](diagnostics/health-logs-swagger.md)
- Зрозуміти налаштований конвеєр контейнерів і розгортання: [Cloud Build](deployment/cloud-build.md)
- Перевірити стан підтримки фонових задач: [задачі та інструкції](jobs/README.md)

Не розміщуйте в цій документації пароль, токен, повний рядок підключення або виробничу кінцеву точку.
