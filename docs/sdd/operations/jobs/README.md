# Фонові задачі та інструкції

У поточній перевіреній структурі BreviERP немає окремого консольного хоста для імпорту, внутрішнього планувальника, черги, механізму повторів із затримкою, розподіленого блокування або періодичного виконання. У `Host.Api` викликається `AddBackgroundJobRegistrations()`, але наразі цей метод не реєструє сервісів. Команди чи процедури для ще не реалізованих задач не визначені.

```text
оператор / cron / CI → погоджена реалізація задачі → сервіс модуля з окремою областю залежностей → PostgreSQL / зовнішній адаптер
```

- [Стан CLI завдань](host-jobs-cli.md)
- [Усунення проблем](troubleshooting.md)

Для нової фонової операції спочатку створіть SDD-специфікацію. Вона має визначати команду запуску, контракт, ідемпотентність, час очікування й поведінку повторів, блокування, спостережуваність, безпечний повтор і відкат. Ніколи не вставляйте секрети або справжні URL кінцевих точок у вивід, задачі трекера чи документацію.
