# Production schema

Code model reviewed 2026-11-05. `Production.Infrastructure.Persistence.ProductionDbContext` owns schema `production`; migration history is `production.__EFMigrationsHistory`. Migration `InitialProduction` creates Employees and FabricNorms ([PRD-001](../../specs/production/001-workshop-references/README.md)); `ProductionOrders` creates Orders, Items and OrderChanges ([PRD-002](../../specs/production/002-production-orders/README.md)); `ProductionTracking` adds Shipments, OrderFiles, TelegramDeliveries, Settings and the stage and cancel columns ([PRD-003](../../specs/production/003-order-tracking/README.md)); `FabricStock` adds FabricStocks, FabricMovements, FabricIssues and FabricIssueLines ([PRD-004](../../specs/production/004-fabric-stock/README.md)); `WorkLog` adds Work and ForecastQueues ([PRD-005](../../specs/production/005-work-log/README.md)); `TimesheetPayroll` adds TimeEntries, TimeChanges, PayrollMonths, PayrollRoles, PayrollPayments, PayrollAdjustments and PayrollIssued ([PRD-006](../../specs/production/006-timesheet-payroll/README.md)); `WorkshopReports` adds PayrollMonths.ReportSnapshot ([PRD-007](../../specs/production/007-workshop-reports/README.md)).

| Table | Identity / relationships / purpose |
| --- | --- |
| Employees | Generated int id. FullName (120), NameKey (120, lower case), Position (80), IsActive, CreatedAt, UpdatedAt, UpdatedByUserId (Identity user id as a value). Unique NameKey among active rows (filtered index `"IsActive"`) |
| FabricNorms | Generated int id. Unique ModelCode (32, Catalog model code as a value), OneColor, TwoColorsMain, TwoColorsAdditional, ThreeColorsMain, ThreeColorsAdditional1, ThreeColorsAdditional2 (numeric(7,3) metres, nullable), UpdatedAt, UpdatedByUserId |
| Orders | Generated int id. Unique Number, QuoteId (Crm КП id as a value), QuoteNumber (40), CustomerId, ClientName (300), ManagerUserId, ManagerName (200), Status (New/Closed/Cancelled), OrderDate, Comment, PriceTier (Retail/Wholesale/Large), unique CreateRequestId and LegacyId (filtered), CopiedFromOrderId, CreatedAt, CreatedByName, UpdatedAt, CancelReason (1000), DeletedAt (soft delete), Version (concurrency) |
| Items | Generated int id, OrderId → Orders (cascade), unique (OrderId, Position). Snapshot: QuoteItemId, QuoteOptionId, ProductId, ArticleId, ModelCode, ModelName, FabricId, FabricCode, FabricName, SewingRate, ReportUnitPrice (numeric(12,2)). Details: Quantity, DueDate, MainColor, AdditionalColors (jsonb list), SizesText, TechnicalChanges, Comment, Applications (jsonb list of kind/place/description/color and, for an embroidery, the saved Crm calculation id with its «ВШ-…» number; no FK), PlannedFabricMeters. Stages (jsonb list of stage numbers 1–9), CurrentStage (int, indexed: the furthest one) |
| Shipments | Generated int id, OrderId → Orders (cascade), ItemId → Items (restrict). Quantity, ShippedOn, Comment (1000), CreatedByName, CreatedAt |
| OrderFiles | Generated int id, OrderId → Orders (cascade), ItemId → Items (set null; null = whole order). Kind (Sizes/Application/Extra/Photo), Name (255), ContentType, Bytes, Url (CDN or old Google Drive link), StorageKey (CDN key; null for an old link), CreatedByName, CreatedAt, DeletedAt |
| TelegramDeliveries | Key OrderId → Orders (cascade, one row per order). Status (NotSent/Sending/Sent/Failed), ChatId, ThreadId, MessageId, Attempts, LastError (500), SentByName, SentAt, Version (concurrency) |
| Settings | One row, Id = 1: TelegramEnabled, TelegramChatId (a Reminders bot group as a value), TelegramThreadId, UpdatedByName, UpdatedAt |
| FabricStocks | Generated int id. FabricId (Reference fabric id as a value), FabricCode (32), FabricName (300), Color (80), ColorKey (80, lower case); unique (FabricCode, ColorKey). Meters numeric(12,2) (may be negative), HasMovements, CreatedAt, UpdatedAt, Version (concurrency), unique LegacyId |
| FabricMovements | Generated int id, StockId → FabricStocks (restrict). Kind (Opening/Receipt/Issue/Adjustment/Reversal), MetersBefore, Delta, MetersAfter, OperationDate, Note, SupplierId (Reference supplier as a value), SupplierName, Document, OrderId, ItemId, OrderNumber, ModelName (snapshot of the target), ReversesMovementId → FabricMovements, IsReversed, CreatedByName, CreatedAt, unique LegacyId |
| FabricIssues | Generated int id, OrderId → Orders, ItemId → Items (restrict). OrderNumber, ModelName, IssuedOn, Note, CreatedByName, CreatedAt, ReversedAt, ReversedByName, ReverseReason, unique LegacyId |
| FabricIssueLines | Generated int id, IssueId → FabricIssues (cascade), StockId → FabricStocks, MovementId → FabricMovements (unique). Purpose (Planned/Replacement/Additional), PlanFabricCode, PlanColorKey, PlannedMeters, FabricCode, FabricName, Color, Meters, CoveredMeters |
| Work | Generated int id, OrderId → Orders, ItemId → Items, EmployeeId → Employees (restrict). EmployeeName (snapshot), Kind (Sewing/Cutting), Quantity, WorkDate (indexed), OverPlan, Reason (500), Comment (1000), Rate numeric(12,2) (item sewing rate snapshot), CreatedByName, CreatedAt, VoidedAt, VoidedByName, VoidReason (500), unique LegacyId |
| ForecastQueues | One row, Id = 1: OrderIds (jsonb list, queue order of «Нове» orders), Version (concurrency), UpdatedByName, UpdatedAt |
| TimeEntries | Generated int id, EmployeeId → Employees (restrict). WorkDate (indexed), Minutes (0–1440, step 15), Version (concurrency), UpdatedByName, UpdatedAt; unique (EmployeeId, WorkDate) |
| TimeChanges | Generated int id, EmployeeId → Employees (restrict). EmployeeName, WorkDate (indexed), BeforeMinutes (null on the first mark), AfterMinutes, ChangedByName, ChangedAt |
| PayrollMonths | Key Month (first day). Stitches, EmbroideryEmployeeId → Employees (restrict), ClosedAt, ClosedByName, Snapshot (jsonb: the kept calculation of a closed month), ReportSnapshot (jsonb: its kept «Звіти цеху»), Version (concurrency), UpdatedByName, UpdatedAt |
| PayrollRoles | Key Role (Master/Chief). EmployeeId → Employees (restrict), UpdatedByName, UpdatedAt |
| PayrollPayments | Generated int id, EmployeeId → Employees (restrict). Month (indexed), EmployeeName, PaidOn, Kind (Advance/Card/Cash/Other), Amount numeric(12,2), Comment (1000), CreatedByName, CreatedAt, VoidedAt, VoidedByName, VoidReason (500) |
| PayrollAdjustments | Generated int id, EmployeeId → Employees (restrict). Month (indexed), EmployeeName, Amount numeric(12,2) (negative = deduction), Reason (500), CreatedByName, CreatedAt, VoidedAt, VoidedByName, VoidReason |
| PayrollIssued | Key (Month, EmployeeId → Employees). Amount numeric(12,2) («Видано»), UpdatedByName, UpdatedAt |
| OrderChanges | Generated bigint id, OrderId → Orders (cascade). ItemId, ItemName, Field, Before, After (display texts), ActorName, At |

The model code and user id are plain values; there are no foreign keys to `catalog`, `crm`, `reference` or `identity`.
