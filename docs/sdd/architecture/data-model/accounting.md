# Accounting schema

Code model reviewed 2026-11-08. `Accounting.Infrastructure.Persistence.AccountingDbContext` owns schema `accounting`; migration history is `accounting.__EFMigrationsHistory`. Migration `InitialAccounting` creates the stage 1 tables and drops the unused stub table `TransactionCategories` of the earlier `InitialAccountingSchema` (whose history row stays in `public`); `AddFinanceMovements` adds operations and transfers, `AddFinanceCounterparties` adds finance counterparties and the counterparty of an operation, `AddFinanceAttachments` adds files of operations, `AddLegacyMovementIdentity` adds the bank identity of moved records, `AddBankStatements` adds uploaded bank statements and their lines ([ACC-001](../../specs/accounting/001-finance/README.md)). [Back to database map](README.md).

| Table | Identity / relationships / purpose |
| --- | --- |
| Accounts | PK Id (uuid v7). Name, Type (text), Currency (char 3), Iban, OpeningMinor (bigint, kopecks), OpeningDate, CutoverBalanceMinor, CutoverConfirmed, CutoverConfirmedAt, CutoverConfirmedBy, Note, Active, SortOrder, Version (concurrency token), CreatedAt, UpdatedAt; index (Active, SortOrder) |
| Categories | PK Id (uuid v7); ParentId FK → Categories (restrict), two levels. Name, Direction (Income/Expense), Scope (Current/LegacyArchive), Note, Active, SortOrder, Version (concurrency token), CreatedAt, UpdatedAt; index (Scope, Direction, ParentId) |
| Transactions | PK Id (uuid v7); AccountId FK → Accounts (restrict), CategoryId FK → Categories (restrict, null only for future bank lines). Date, Type (Income/Expense), AmountMinor (bigint > 0), Currency (char 3, from the account), CounterpartyKind (Financial/Client/Supplier) and CounterpartyId (text: uuid or supplier number; both set or both null, no FK), OneoffName, Description, Comment, Source, Verification, Scope, Status (Active/Void), Version (concurrency token), CreatedBy, CreatedAt, UpdatedAt, ExternalId (200, line id in the bank or «Домашня бухгалтерія»), Fingerprint (128, bank line hash), BankTransactionId (200), BankPurpose (1500, default empty); indexes (Scope, Status, Date, Id), (AccountId, Status, Scope, Date), CategoryId, (CounterpartyKind, CounterpartyId), (Verification, Date), Fingerprint, ExternalId. Moved archive rows keep their old ids |
| Transfers | PK Id (uuid v7); FromAccountId and ToAccountId FK → Accounts (restrict), check: different accounts, AmountMinor > 0. Date, Currency, Note, Source, Scope, Status, Version, CreatedBy, CreatedAt, UpdatedAt, ExternalId (200), Fingerprint (128); indexes (Scope, Status, Date, Id), FromAccountId, ToAccountId, Fingerprint, ExternalId |
| Counterparties | PK Id (uuid v7); DefaultCategoryId FK → Categories (restrict), MergedIntoId FK → Counterparties (restrict). Name, Edrpou (digits), Iban, BankName, Aliases (one per line), AutoApplyCategory, Note, SearchText (lower-case names, codes, IBAN), Verified, Active, Version (concurrency token), CreatedAt, UpdatedAt; indexes (Active, Name), Edrpou, Iban. Finance counterparties only («Фінансові») |
| Attachments | PK Id (uuid v7); TransactionId FK → Transactions (restrict). FileName, ContentType (application/pdf, image/jpeg, image/png), SizeBytes (check 1 byte to 10 MiB), Sha256 (char 64), StorageKey (unique, `finance/<transactionId>/<attachmentId>.<ext>` in the private bucket), CreatedBy, CreatedAt, DeletedAt, DeletedBy; index (TransactionId, DeletedAt). A removed file keeps its row |
| BankStatements | PK Id (uuid v7); AccountId FK → Accounts (restrict). FileName, FileHash (char 64, SHA-256), Status (Preview/Booked), LineCount, FirstDate, LastDate, TransactionCount, TransferCount, CreatedBy, CreatedAt, BookedBy, BookedAt, Version (concurrency token); unique (AccountId, FileHash) — the same file opens the statement uploaded before; index CreatedAt |
| BankStatementLines | PK Id (uuid v7); StatementId FK → BankStatements (cascade). RowNumber, Date, Time, Type, AmountMinor, Currency (null on an error line), BankName, Edrpou, Iban, Purpose (1500), Document, BankId (200), Fingerprint (64, the old Calculator formula), Error, RawJson (cells by header), Duplicate (None/Probable/Exact), DuplicateNote, TransferAccountId, CounterpartyKind/CounterpartyId (both or neither) with CounterpartyName and CounterpartyVerified, CategoryId, OneoffName, Description, Comment, Excluded, State, TransactionId/TransferId (the record a booked line became), CreatedCounterparty (the booking created its finance counterparty; a rollback may archive it); no links to accounts, categories or records (a draft until booking); indexes (StatementId, RowNumber), (StatementId, State), TransactionId, TransferId |
| AuditEntries | PK Id (identity). Entity (Account/Category/Transaction/Transfer/Counterparty), EntityId, Action, By (e-mail), At, BeforeJson, AfterJson (jsonb snapshots); index (Entity, EntityId, Id), index At. Append-only change log |

Balances are counted on read and not stored. Crm clients (`Customers.PublicId`) and Reference suppliers (`Suppliers.Id`) are stored by id in `Transactions.CounterpartyId` without database links; names are read through the host readers.
