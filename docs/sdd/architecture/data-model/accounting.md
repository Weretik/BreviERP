# Accounting schema

Code model reviewed 2026-11-05. `Accounting.Infrastructure.Persistence.AccountingDbContext` owns schema `accounting`; migration history is `accounting.__EFMigrationsHistory`. Migration `InitialAccounting` creates the stage 1 tables and drops the unused stub table `TransactionCategories` of the earlier `InitialAccountingSchema` (whose history row stays in `public`); `AddFinanceMovements` adds operations and transfers, `AddFinanceCounterparties` adds finance counterparties and the counterparty of an operation ([ACC-001](../../specs/accounting/001-finance/README.md)). [Back to database map](README.md).

| Table | Identity / relationships / purpose |
| --- | --- |
| Accounts | PK Id (uuid v7). Name, Type (text), Currency (char 3), Iban, OpeningMinor (bigint, kopecks), OpeningDate, CutoverBalanceMinor, CutoverConfirmed, CutoverConfirmedAt, CutoverConfirmedBy, Note, Active, SortOrder, Version (concurrency token), CreatedAt, UpdatedAt; index (Active, SortOrder) |
| Categories | PK Id (uuid v7); ParentId FK → Categories (restrict), two levels. Name, Direction (Income/Expense), Scope (Current/LegacyArchive), Note, Active, SortOrder, Version (concurrency token), CreatedAt, UpdatedAt; index (Scope, Direction, ParentId) |
| Transactions | PK Id (uuid v7); AccountId FK → Accounts (restrict), CategoryId FK → Categories (restrict, null only for future bank lines). Date, Type (Income/Expense), AmountMinor (bigint > 0), Currency (char 3, from the account), CounterpartyKind (Financial/Client/Supplier) and CounterpartyId (text: uuid or supplier number; both set or both null, no FK), OneoffName, Description, Comment, Source, Verification, Scope, Status (Active/Void), Version (concurrency token), CreatedBy, CreatedAt, UpdatedAt; indexes (Scope, Status, Date, Id), (AccountId, Status, Scope, Date), CategoryId, (CounterpartyKind, CounterpartyId), (Verification, Date) |
| Transfers | PK Id (uuid v7); FromAccountId and ToAccountId FK → Accounts (restrict), check: different accounts, AmountMinor > 0. Date, Currency, Note, Source, Scope, Status, Version, CreatedBy, CreatedAt, UpdatedAt; indexes (Scope, Status, Date, Id), FromAccountId, ToAccountId |
| Counterparties | PK Id (uuid v7); DefaultCategoryId FK → Categories (restrict), MergedIntoId FK → Counterparties (restrict). Name, Edrpou (digits), Iban, BankName, Aliases (one per line), AutoApplyCategory, Note, SearchText (lower-case names, codes, IBAN), Verified, Active, Version (concurrency token), CreatedAt, UpdatedAt; indexes (Active, Name), Edrpou, Iban. Finance counterparties only («Фінансові») |
| AuditEntries | PK Id (identity). Entity (Account/Category/Transaction/Transfer/Counterparty), EntityId, Action, By (e-mail), At, BeforeJson, AfterJson (jsonb snapshots); index (Entity, EntityId, Id), index At. Append-only change log |

Balances are counted on read and not stored. Crm clients (`Customers.PublicId`) and Reference suppliers (`Suppliers.Id`) are stored by id in `Transactions.CounterpartyId` without database links; names are read through the host readers.
