# Warehouse schema

Code model reviewed 2026-11-11. `Warehouse.Infrastructure.Persistence.WarehouseDbContext` owns schema `warehouse`; migration history is `warehouse.__EFMigrationsHistory`. Migration `InitialWarehouse` creates the four tables and copies the rows of the former `production` stock tables with their ids, then drops those tables ([WH-001](../../specs/warehouse/001-warehouse-module/README.md); rules from [PRD-004](../../specs/production/004-fabric-stock/README.md)). `WarehouseLedgerRules` adds the operation journal and restates movement chains by operation date ([WH-002](../../specs/warehouse/002-ledger-rules/README.md)). `WarehouseMovementRevisions` adds the void mark, the revision number and the journal of edits ([WH-003](../../specs/warehouse/003-movement-revisions/README.md)). `WarehouseIssueByCutting` links movements to issue lines, adds the products cut and saved item plans ([WH-004](../../specs/warehouse/004-issue-by-cutting/README.md)).

| Table | Identity / relationships / purpose |
| --- | --- |
| FabricStocks | Generated int id. FabricId (Reference fabric id as a value), FabricCode (32), FabricName (300), Color (80), ColorKey (80, NFC lower case uk-UA); unique (FabricCode, ColorKey). Codes of an alias group (FAB-023/067, FAB-078/077) with one colour key form a pair; lines are never merged. Meters numeric(12,2) (may be negative), HasMovements, CreatedAt, UpdatedAt, Version (concurrency), unique LegacyId |
| FabricMovements | Generated int id, StockId → FabricStocks (restrict). Kind (Opening/Receipt/Issue/Adjustment/Reversal), MetersBefore, Delta, MetersAfter, OperationDate, Note, SupplierId (Reference supplier as a value), SupplierName, Document, OrderId, ItemId, OrderNumber, ModelName (snapshot of the target), Destination (160, issue without an order), OperationId (uuid, indexed; the form submission), ReversesMovementId → FabricMovements, IssueLineId → FabricIssueLines (restrict, indexed; the issue line the movement spends for), IsReversed, IsVoided («Скасовано», delta 0), Revision (concurrency token), CreatedByName, CreatedAt, unique LegacyId. The chain of a line runs by OperationDate, CreatedAt, Id |
| FabricMovementRevisions | Generated int id, MovementId → FabricMovements, unique (MovementId, Number). Action (Edit/Void/Restore); Before*/After* StockId (→ FabricStocks), OperationDate, Delta, SupplierName, Document, Destination, IsVoided; Reason (500), CreatedByName, CreatedAt, OperationId, RestoresRevisionId → FabricMovementRevisions, IsUndone. All FKs restrict |
| StockOperations | Id = the form's operation id (uuid). Kind, RequestHash (SHA-256), UserId, FabricCode (canonical), ColorKey, Color, MetersAfter numeric(14,2), CreatedAt. Repeats return the saved result |
| FabricIssues | Generated int id, OrderId, ItemId (Production order and item as values, no FK). OrderNumber, ModelName, IssuedOn, IssuedQuantity (products cut; null for older issues), OperationId (unique), PlanVersion, Note, CreatedByName, CreatedAt, ReversedAt, ReversedByName, ReverseReason, unique LegacyId |
| FabricIssueLines | Generated int id, IssueId → FabricIssues (cascade), StockId → FabricStocks (the pair of its largest movement); movements point to the line. Purpose (Planned/Replacement/Additional), PlanFabricCode, PlanColorKey, PlannedMeters (plan of the products cut), PlanCoverage, FabricCode, FabricName, Color, Meters (restated from its movements), CoveredMeters (0 when every movement is voided), Layer (Upper/Lining/Insulation/Fleece), Note (500) |
| FabricItemPlans | Generated int id, OrderId, ItemId (unique; values, no FK), Quantity, Version (concurrency token), UpdatedByName, UpdatedAt. Saved at the first issue of an item; changed only by «Оновити план» |
| FabricItemPlanParts | Generated int id, PlanId → FabricItemPlans (cascade). FabricCode, Color, ColorKey, Layer, Meters numeric(12,2) |
