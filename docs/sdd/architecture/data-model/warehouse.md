# Warehouse schema

Code model reviewed 2026-11-11. `Warehouse.Infrastructure.Persistence.WarehouseDbContext` owns schema `warehouse`; migration history is `warehouse.__EFMigrationsHistory`. Migration `InitialWarehouse` creates the four tables and copies the rows of the former `production` stock tables with their ids, then drops those tables ([WH-001](../../specs/warehouse/001-warehouse-module/README.md); rules from [PRD-004](../../specs/production/004-fabric-stock/README.md)). `WarehouseLedgerRules` adds the operation journal and restates movement chains by operation date ([WH-002](../../specs/warehouse/002-ledger-rules/README.md)).

| Table | Identity / relationships / purpose |
| --- | --- |
| FabricStocks | Generated int id. FabricId (Reference fabric id as a value), FabricCode (32), FabricName (300), Color (80), ColorKey (80, NFC lower case uk-UA); unique (FabricCode, ColorKey). Codes of an alias group (FAB-023/067, FAB-078/077) with one colour key form a pair; lines are never merged. Meters numeric(12,2) (may be negative), HasMovements, CreatedAt, UpdatedAt, Version (concurrency), unique LegacyId |
| FabricMovements | Generated int id, StockId → FabricStocks (restrict). Kind (Opening/Receipt/Issue/Adjustment/Reversal), MetersBefore, Delta, MetersAfter, OperationDate, Note, SupplierId (Reference supplier as a value), SupplierName, Document, OrderId, ItemId, OrderNumber, ModelName (snapshot of the target), Destination (160, issue without an order), OperationId (uuid, indexed; the form submission), ReversesMovementId → FabricMovements, IsReversed, CreatedByName, CreatedAt, unique LegacyId. The chain of a line runs by OperationDate, CreatedAt, Id |
| StockOperations | Id = the form's operation id (uuid). Kind, RequestHash (SHA-256), UserId, FabricCode (canonical), ColorKey, Color, MetersAfter numeric(14,2), CreatedAt. Repeats return the saved result |
| FabricIssues | Generated int id, OrderId, ItemId (Production order and item as values, no FK). OrderNumber, ModelName, IssuedOn, Note, CreatedByName, CreatedAt, ReversedAt, ReversedByName, ReverseReason, unique LegacyId |
| FabricIssueLines | Generated int id, IssueId → FabricIssues (cascade), StockId → FabricStocks, MovementId → FabricMovements (unique). Purpose (Planned/Replacement/Additional), PlanFabricCode, PlanColorKey, PlannedMeters, FabricCode, FabricName, Color, Meters, CoveredMeters |
