# Crm schema

`Crm.Infrastructure.Persistence.CrmDbContext` owns schema `crm` («Менеджер сервісу»: clients, КП and manager tasks) in the shared PostgreSQL database; migration history is `crm.__EFMigrationsHistory`. Reviewed 2026-11-04.

`RemoveCodexQuoteTables` (2026-11-04) drops the earlier quote, custom sewing, document, PDF, email, delivery, production-package and introduction tables and their trigger functions; their data is not kept. `AddQuotes` then adds the КП tables of [QTE-001](../../specs/crm/003-quotes/README.md); `AddQuoteSettings` adds «Налаштування КП»; `AddQuoteSending` adds Gmail per staff member, the sent-letter log and `Quotes.LastSentAt`; `AddQuoteIntroductions` adds the introduction fields of `Quotes` and «Готові шаблони».

| Table | Identity / relationships / purpose |
| --- | --- |
| Customers                  | Generated typed long ID, unique Guid PublicId, kind/names/tax identity, typed int Identity owner reference, active, optimistic revision, UTC audit; restrictive self-FK MergedIntoId preserves merge survivor; nullable KeepinSyncedAt (last applied KeepinCRM client sync, migration AddCustomerKeepinSyncedAt)                                               |
| CustomerContacts           | Generated typed long ID/PublicId, restrictive Customer FK, name/position/active/primary. Partial unique index permits at most one active primary per customer                                                                                               |
| ContactChannels            | Generated typed long ID, Contact FK, email/phone/raw/normalized values. Unique within contact/kind/normalized value, not globally unique; searchable normalization                                                                                          |
| CustomerExternalIdentities | Generated typed long ID, restrictive Customer FK. Unique source/type/externalId across customers; source IDs never replace Brevi PK                                                                                                                         |
| MutationRequests           | Technical long ID; unique actor/operation/requestId, input hash, customer PublicId, successful intent/result audit JSON and UTC time. Atomic with business write; no secret/auth credential data                                                            |
| Quotes | Generated long ID; unique Number «n-month-year» and unique (NumberYear, NumberMonth, NumberSequence); Kind (Request, Introduction), Status (Draft, Sent); internal name, optional CustomerId (no FK), recipient/company texts; author and responsible Identity user id with their names; LastSentAt (null for a draft); IntroLayout (General, Summer, Winter), RecipientEmail and LetterName only for an introduction; Version is the optimistic concurrency token |
| QuoteItems | Generated long ID, cascade Quote FK, Position, Kind (Sewing, Ppe, OneOffPpe), Catalog ProductId (null only for OneOffPpe, check constraint), frozen client texts: code, name, subtitle, description, site link, photo, season, supplier link |
| QuoteItemOptions | Generated long ID, cascade item FK, Position; fabric variant ArticleId/FabricId for sewing; title/details; three price tiers as RetailSource/Manual/Shown, WholesaleSource/Manual/Shown, LargeSource/Manual/Shown (numeric(12,2), non-negative); manual reason with who/when; PricesTakenAt |
| StaffMailboxes | Gmail per staff member: `UserId` (Identity user id, primary key, no FK), Email, ProtectedRefreshToken (Data Protection), ConnectedByName, ConnectedAt |
| QuoteSendings | A letter with a КП that Gmail accepted: QuoteId (FK, cascade), QuoteVersion, sender id and name, FromEmail, To, Subject, ProviderMessageId, SentAt |
| QuoteIntroTemplates | «Готовий шаблон» of an introduction: Name with unique lower-case NameKey, Layout, LetterName, jsonb Pages (season with ProductId, ArticleId and the product and fabric names, no prices), author id and name (no FK), CreatedAt |
| QuoteSettings | One row (`Id` = 1, check constraint): jsonb sections Company, Email, Pdf, Introduction, LetterVariants, StaffContacts (keyed by Identity user id, no FK); UpdatedByName, UpdatedAt; Version is the optimistic concurrency token |
| ManagerTasks | Generated long ID shown as «ЗД-0142»; title, description, assignee and author Identity user id with names, DueAt, IsUrgent, Status (New, InProgress, Done), optional client PublicId with its name (no FK), CompletedAt only when Done (check constraint); Version is the optimistic concurrency token ([TSK-001](../../specs/crm/004-manager-tasks/README.md), migration AddManagerTasks) |
| ManagerTaskSteps | Generated long ID, cascade task FK, Position, text, IsDone |
| ManagerTaskEvents | Generated long ID, cascade task FK, Kind, who (user id and name), when, kind-specific details |

No physical FK or EF navigation to Identity, Reference or Catalog: Catalog ids and Identity user ids are plain values read through Host.Api adapters. Clients are not Identity users. Customer root row locks serialize writes; revisions are concurrency tokens; merge keeps the victim inactive with a survivor link. The KeepinCRM sync keeps customers that a КП uses (`Quotes.CustomerId`).
