# Crm schema

`Crm.Infrastructure.Persistence.CrmDbContext` owns schema `crm` («Менеджер сервісу»: clients, КП, manager tasks, leads, site requests and the embroidery price settings) in the shared PostgreSQL database; migration history is `crm.__EFMigrationsHistory`. Reviewed 2026-11-04.

`RemoveCodexQuoteTables` (2026-11-04) drops the earlier quote, custom sewing, document, PDF, email, delivery, production-package and introduction tables and their trigger functions; their data is not kept. `AddQuotes` then adds the КП tables of [QTE-001](../../specs/crm/003-quotes/README.md); `AddQuoteSettings` adds «Налаштування КП»; `AddQuoteSending` adds Gmail per staff member, the sent-letter log and `Quotes.LastSentAt`; `AddQuoteIntroductions` adds the introduction fields of `Quotes` and «Готові шаблони»; `AddQuoteHistoryAndArchive` adds `QuoteEvents` (filled from existing КП and sent letters) and `Quotes.ArchivedAt`/`ArchivedByName`.

| CustomerContacts           | Generated typed long ID/PublicId, restrictive Customer FK, name/position/active/primary. Partial unique index permits at most one active primary per customer                                                                                               |
| ContactChannels            | Generated typed long ID, Contact FK, email/phone/raw/normalized values. Unique within contact/kind/normalized value, not globally unique; searchable normalization                                                                                          |
| CustomerExternalIdentities | Generated typed long ID, restrictive Customer FK. Unique source/type/externalId across customers; source IDs never replace Brevi PK                                                                                                                         |
| MutationRequests           | Technical long ID; unique actor/operation/requestId, input hash, customer PublicId, successful intent/result audit JSON and UTC time. Atomic with business write; no secret/auth credential data                                                            |
| Quotes | Generated long ID; unique Number «n-month-year» and unique (NumberYear, NumberMonth, NumberSequence); Kind (Request, Introduction), Status (Draft, Sent); internal name, optional CustomerId (no FK), recipient/company texts; author and responsible Identity user id with their names; LastSentAt (null for a draft); IntroLayout (General, Summer, Winter), RecipientEmail and LetterName only for an introduction; ArchivedAt and ArchivedByName while in «Архів»; Version is the optimistic concurrency token |
| QuoteItems | Generated long ID, cascade Quote FK, Position, Kind (Sewing, Ppe, OneOffPpe, CustomSewing, Embroidery), Catalog ProductId (null for OneOffPpe and Embroidery; for CustomSewing null or the changed model; check constraint), EmbroideryCalculationId (set only for Embroidery, check constraint, no FK; migration AddQuoteEmbroideryItems), frozen client texts: code, name, subtitle, description, site link, photo, season, supplier link |
| QuoteItemOptions | Generated long ID, cascade item FK, Position; fabric variant ArticleId/FabricId for sewing; title/details; three price tiers as RetailSource/Manual/Shown, WholesaleSource/Manual/Shown, LargeSource/Manual/Shown (numeric(12,2), non-negative); manual reason with who/when; PricesTakenAt; FabricId/FabricMeters (numeric(12,4)) mirror the first row of QuoteItemOptionFabrics |
| QuoteItemOptionFabrics | Generated long ID, cascade option FK, Position; FabricId (Reference id, no FK), Name (max 200), Meters (numeric(12,4), > 0); the fabrics of a «Виріб з нуля» variant (R-26) or of a model row in another fabric (R-27) |
| QuoteItemLines | «Виріб з нуля» composition: generated long ID, cascade item FK, Position, Kind (Accessory, Operation, Service, Fabric), Reference id (no FK; 0 for a service), CostCode (service only, Reference other-cost code), name and unit copied when priced, Quantity (> 0), ManualMinutes (operation only) |
| QuoteEvents | «Історія змін» of a КП: generated long ID, QuoteId (FK, cascade), Kind (Created, Saved, Sent, Repriced, ResponsibleChanged, Archived, Restored, Copied, Imported), actor Identity user id and name (no FK), Details (≤ 500), At; index (QuoteId, At) |
| StaffMailboxes | Gmail per staff member: `UserId` (Identity user id, primary key, no FK), Email, ProtectedRefreshToken (Data Protection), ConnectedByName, ConnectedAt |
| QuoteSendings | A letter with a КП that Gmail accepted: QuoteId (FK, cascade), QuoteVersion, sender id and name, FromEmail, To, Subject, ProviderMessageId, SentAt |
| QuoteIntroTemplates | «Готовий шаблон» of an introduction: Name with unique lower-case NameKey, Layout, LetterName, jsonb Pages (season with ProductId, ArticleId and the product and fabric names, no prices), author id and name (no FK), CreatedAt |
| QuoteSettings | One row (`Id` = 1, check constraint): jsonb sections Company, Email, Pdf, Introduction, LetterVariants, StaffContacts (keyed by Identity user id, no FK); UpdatedByName, UpdatedAt; Version is the optimistic concurrency token |
| ManagerTasks | Generated long ID shown as «ЗД-0142»; title, description, assignee and author Identity user id with names, DueAt, IsUrgent, Status (New, InProgress, Done), optional client PublicId with its name (no FK), CompletedAt only when Done (check constraint); Version is the optimistic concurrency token ([TSK-001](../../specs/crm/004-manager-tasks/README.md), migration AddManagerTasks); LeadId (no FK) for a «Подзвонити» task of a lead (migration AddLeads) |
| EmbroiderySettings | One row (Id 1): «Ціна вишивки › Налаштування» as one jsonb `Content` (rates, three named markups, materials, hoops, extra costs with nullable rates), UpdatedByName, UpdatedAt, Version concurrency token ([EMB-001](../../specs/crm/005-embroidery-price/README.md), migration AddEmbroiderySettings) |
| EmbroideryCalculations | Generated long ID shown as «ВШ-0042»: «Ціна вишивки › Збережені», written once; Name, optional client PublicId with its name (no FK), Mode, Quantity, jsonb Input, Snapshot (stitch rate + settings content) and Result, Incomplete, creator id and name, CreatedAt (indexed); LegacyId (≤ 64, unique when set) of a record moved from the old calculator's archive; MockupMediaFileId (nullable, a Media file, no FK) for «Макет» (migrations AddEmbroideryCalculations, AddEmbroideryArchiveLegacyId, AddEmbroideryMockup) |
| Leads | Generated long ID; unique SourceId (the sheet «ID», > 0); company fields from the sheet «Лиды Brevi» (category, company, region, industry, scale, signal and its date and link, why 50+, offer, website, contacts, whom to call, tenders, call reason, reliability, email, AddedOn), SheetNotes (manager columns at the first sync), InSheet; work: owner Identity user id and name (both or neither, check constraint, no FK), TakenAt, Stage (New, InWork, Talking, Offer, Client, Closed), LastResultName, LastCallAt, NextContactAt, CallCount, SyncedAt; Version is the optimistic concurrency token ([LEAD-001](../../specs/crm/006-leads/README.md), migration AddLeads) |
| LeadCalls | Generated long ID, cascade lead FK, who (user id and name), At, ResultId (no FK) with ResultName and Outcome at the time, Comment, NextContactAt; written once |
| LeadCallResults | Generated long ID: «Довідники › Результати дзвінка», Name, Outcome, RetryDays only for Retry (check constraint), IsActive, Position; 8 rows seeded by AddLeads |
| LeadCategories | Code (primary key, from the sheet) and the director's Description |
| LeadSyncStates | One row `google-leads`: last run, last success, rows, added, updated, last error |
| SiteRequests | Generated long ID: a request from the site form «Заявка» ([LEAD-002](../../specs/crm/007-site-requests/README.md), migration AddSiteRequests); Phone, Workwear, Quantity, Comment, Locale, optional attachment FileName and CDN FileUrl; Status (New, InWork, Done, Spam) as text; owner Identity user id and name (no FK), TakenAt, ClosedAt, Note; CreatedAt (indexed), NotifiedAt or NotifyError of the Telegram message, UpdatedAt; Version is the optimistic concurrency token |
| ManagerTaskSteps | Generated long ID, cascade task FK, Position, text, IsDone |
| ManagerTaskEvents | Generated long ID, cascade task FK, Kind, who (user id and name), when, kind-specific details |

No physical FK or EF navigation to Identity, Reference or Catalog: Catalog ids and Identity user ids are plain values read through Host.Api adapters. Clients are not Identity users. Customer root row locks serialize writes; revisions are concurrency tokens; merge keeps the victim inactive with a survivor link. The KeepinCRM sync keeps customers that a КП uses (`Quotes.CustomerId`).
